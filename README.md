# 🛡️ Multi-Agent Cybersecurity Threat Monitoring System

> **An LLM-powered multi-agent platform for detecting, analyzing, and correlating cybersecurity threats across emails, system logs, and network activities.**

## 📌 Overview

The **Multi-Agent Cybersecurity Threat Monitoring System** is an intelligent cybersecurity platform designed to detect and analyze threats across multiple security data sources.

The system combines **Large Language Models (LLMs)** with specialized cybersecurity agents to identify suspicious activities, explain potential threats, correlate alerts, and provide actionable recommendations to security analysts.

Unlike traditional security systems that often analyze security events independently, this project uses a **Contextual Recommendation System** to correlate alerts from emails, logs, and network activities to identify coordinated and multi-stage attacks.

## 🎯 Problem Statement

Traditional cybersecurity monitoring systems often rely heavily on static rules and isolated security tools. This can make it difficult to identify complex attacks that occur across multiple sources.

For example:

```text
Phishing Email
      ↓
Compromised Account
      ↓
Suspicious Server Activity
      ↓
Network Reconnaissance
      ↓
Possible Multi-Stage Attack
```

Analyzing each event independently may cause these activities to appear unrelated.

This project addresses this problem by using a **multi-agent architecture combined with LLM-based semantic analysis** to correlate security events and provide a broader understanding of potential attacks.

## 🧩 System Architecture

The system consists of three specialized monitoring agents:

### 1. Email Verification Agent

Analyzes emails to identify:

* Phishing attempts
* Spam
* Suspicious content
* Malicious patterns

### 2. Log Analysis Agent

Analyzes system and server logs to identify:

* Suspicious activities
* Anomalies
* Brute-force attempts
* Potential malicious behavior

### 3. Network/IP Scanning Agent

Analyzes network and IP activities to identify:

* Port scanning
* Suspicious connections
* Network reconnaissance
* Potential intrusion attempts

### 4. Contextual Recommendation System

The recommendation layer correlates alerts generated by different agents.

```text
                ┌──────────────────────┐
                │   Email Agent        │
                └──────────┬───────────┘
                           │
                ┌──────────▼───────────┐
                │                      │
                │ Contextual           │
                │ Recommendation       │
                │ System               │
                │                      │
                └──────────┬───────────┘
                           │
                ┌──────────▼───────────┐
                │ Threat Correlation   │
                │ & Explanation        │
                └──────────┬───────────┘
                           │
          ┌────────────────┼────────────────┐
          ▼                ▼                ▼
      Analyst          Manager          Employee
      Dashboard        Dashboard        Alerts
```

## 👥 User Roles

### Manager

Provides an overview of cybersecurity activity and threat information.

### Employee

Allows users to view security alerts related to emails, logs, and network activities.

### Analyst

Provides security analysts with tools to investigate correlated alerts, filter threats, add annotations, and review LLM-generated explanations.

### Attacker

Provides a controlled environment for simulating phishing, log, and network attacks to evaluate the monitoring system.

## 📊 Datasets

The system uses cybersecurity datasets for evaluation:

### SpamAssassin Email Corpus

Used for detecting spam and phishing-related email patterns.

### CIC-IDS 2017

Used for evaluating network and system attack detection, including attack categories such as brute force, DDoS, infiltration, and botnet activity.

### Simulated IP Scanning Dataset

Used to represent network reconnaissance activities such as port scanning and suspicious connection attempts.
